# EV Charging Station Placement and Trip Planning System

## Project Overview

The EV Charging Station Placement and Trip Planning System is a C-based application developed as part of the Design and Analysis of Algorithms (DAA) course.

The project aims to simulate electric vehicle route planning and charging station placement using graph algorithms, greedy techniques, sorting and searching algorithms, and performance benchmarking.

## Objectives

- Represent road networks using graphs.
- Calculate routes using shortest-path algorithms.
- Compare charging station placement strategies.
- Organize and search station-related data efficiently.
- Evaluate algorithm performance through benchmarking.

## Technologies Used

- Programming Language: C
- Compiler: GCC
- Development Environment: Visual Studio Code
- Version Control: Git and GitHub

## Implemented Modules

- Graph representation
- Dijkstra's shortest-path algorithm
- Bellman-Ford algorithm
- Fastest route calculation
- Sorting and searching algorithms
- Advanced algorithm implementations
- Station comparison
- Stress benchmarking

## Project Structure

- `main.c` – Application entry point
- `graph.c / graph.h` – Graph operations
- `dijkstra.c / dijkstra.h` – Dijkstra's algorithm
- `bellman_ford.c / bellman_ford.h` – Bellman-Ford algorithm
- `ev_planner.c / ev_planner.h` – EV planning functionality
- `advanced_algorithms.c / advanced_algorithms.h` – Additional algorithms
- `station_comparison.c / station_comparison.h` – Station comparison
- `stress_benchmark.c / stress_benchmark.h` – Performance benchmarking

## Compilation

The project can be compiled using the provided Makefile or GCC, depending on the available build configuration.
